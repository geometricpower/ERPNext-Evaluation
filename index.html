Negotiation & next steps

Leverage partnership for optimal terms

NED and Matiyas are partners — negotiate a unified package, not separate contracts.
🎯 Unified negotiation with NED+Matiyas
Single contract: Request a combined proposal that leverages NED's local presence + Matiyas technical backend under one commercial structure.
Avoid double payment: The combined cost should be less than ₦102M + $96k. Negotiate a package discount for using both.
Support structure: Define clear roles — NED for on-site training, Matiyas for technical escalations.
Payment terms: Milestone-based, not 50% upfront.
📋 Fallback options
Cloudrock: Request pricing urgently — may serve as alternative local layer if NED partnership doesn't close.
Convergenix: Request pricing, though technical gap with Matiyas is significant.
Reference checks: Request joint client references from NED+Matiyas working together.
✅ Recommended negotiation target
  • Target combined price: ₦150M - ₦170M all-in (3-year support) — lower than ₦102M + $96k (~₦249M).
  • Scope clarity: NED handles all local training, change management, and user support; Matiyas handles technical configuration, customizations, and remote backend.
  • Payment milestones: 30% signing, 30% at core go-live, 30% at full rollout, 10% after 3 months stabilization.
Partner model creates negotiation leverage — don't accept additive pricing10 / 12
